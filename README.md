# Kachow - AI Vehicle Recognition

AI-powered car identification system using multi-API integration and blackboard architecture to accurately identify vehicles from photos.

## Features
- **Multi-API Integration**: Combines machine learning models, OpenAI, and Gemini APIs
- **Blackboard Architecture**: Compares results across different AI services for improved accuracy
- **Model Training**: Custom ML model training and result comparison algorithms
- **Real-time Processing**: Instant vehicle identification from photo input

## Tech Stack
- **AI/ML**: OpenAI API, Gemini API, Custom ML Models
- **Architecture**: Blackboard pattern for multi-agent decision making
- **Backend**: Python, API integration
- **Processing**: Image recognition, result comparison algorithms

## How It Works
1. Upload vehicle photo
2. System processes image through multiple AI services
3. Blackboard architecture compares and weighs results
4. Returns most accurate vehicle identification

Built for software architecture class to demonstrate complex system design patterns and multi-API coordination.
